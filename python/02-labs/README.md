# 02 — Labs | Python

## Sobre esta pasta

Esta pasta reúne os desafios práticos de Python realizados durante meus estudos no **freeCodeCamp**.

Diferentemente dos workshops, os labs exigem maior autonomia para interpretar problemas, desenvolver soluções e aplicar os conhecimentos adquiridos.

## Objetivos

- Desenvolver raciocínio lógico e resolução de problemas.
- Aplicar conceitos aprendidos nos workshops.
- Praticar a construção de algoritmos.
- Aprender a identificar e corrigir erros.
- Reduzir gradualmente a dependência de tutoriais e ferramentas de IA.

## Organização

Cada lab poderá conter:

- **Código `.py`:** solução desenvolvida para o desafio.
- **`NOTAS.md`:** registro do raciocínio utilizado, dificuldades, erros e aprendizados.

## Uso de Inteligência Artificial

A IA poderá ser utilizada como ferramenta de aprendizagem para:

- Explicar conceitos ainda não compreendidos.
- Fazer perguntas que estimulem o raciocínio.
- Oferecer dicas progressivas.
- Ajudar a compreender erros.

**Regra pessoal:** priorizar a construção da solução por conta própria, evitando solicitar códigos completos antes de tentar resolver o problema.

## Critério de conclusão

Um lab será considerado concluído quando a solução atender aos requisitos propostos e eu conseguir explicar seu funcionamento e as decisões tomadas.
